# IISwCBP
=========

This repository is dedicated for the development of the MSc. Dissertation named "Integrating Industrial Systems with Cloud-based Platforms for Connectivity and Efficiency" made by the Polytechnic university of Leiria's student Judá Imbó during 2024 and 2025.

Este repositório é dedicado ao desenvolvimento da dissertação do mestrado com o tema "Integrating Industrial Systems with Cloud-based Platforms for Connectivity and Efficiency" elaborado pelo estudante do Politécnico de Leiria Judá Imbó durante o ano de 2024 e 2025
