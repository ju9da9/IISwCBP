# PLC Configuration - IIoT



**Explicar que o programa TIA Portal está configurado para conectar o S7-1500 com CPU X simulado - para o PLC físico, no caso de ter apenas o PLC físico utilizado neste trabalho. Mas se tiver o CPU simulado neste trabalho em formato hardware, não necessita de utilizar o TRCV_C e o TSEND_C, fazendo todos os procedimentos de configuração OPC UA neste PLC.**

**Falar como configurar o OPC UA Server no tia portal**


Para fazer a configuração do IOT2050 pode seguir os tutoriais da página [Git Hub da Siemens](https://github.com/SIMATICmeetsLinux/IOT2050-Setting-Up-Example-Image), onde explica com detalhe todos os passos necessários para o funcionamento do IIoT Gateway. Caso seja mais prático, pode utilizar o [PDF](https://github.com/ju9da9/IISwCBP/blob/main/PLC%20Configuration%20-%20IIoT/iot2050_operating_instructions_en_en-US.pdf) da Siemens com os mesmos tutoriais guardado no repositório.
